### Invariants

- Only DocumentRuntime/host owns source, provider binding, dependency graphs and revision authority.
- Application orchestration may coordinate revision change and explicit restart, never create a second scheduler/evaluator.
- Transport owns deadline, correlation, termination and pending Promise settlement; no Python codegen, scope, or mathematical decision.
- P0009 diagnostic structures are language-neutral; presentation/i18n and pedagogical help remain future UI work.
- No automatic replay after timeout/crash. Only an explicit caller request runs the existing selective recalculation.
- A browser success of an **opt-in** test path does not prove the student's active UI is migrated away from the old CASEngine.
